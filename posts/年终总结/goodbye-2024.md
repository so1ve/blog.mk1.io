## 2024 大事记

### Ray 组了一台 NAS！

2024 年 4 月份左右，Ray 组了一台 NAS 🥰 说是 NAS 更准确点应该叫 HomeLab，毕竟上面跑了一大堆的服务，存储反而变成了附加功能（

从购置开始 Ray 又不断加了不少东西进去，写下这篇文章时 NAS 上的配置如下：

| 名称     | 型号                            | 来源       |
| -------- | ------------------------------- | ---------- |
| CPU      | Intel i3-9100t 好像是全新散片？ | 闲鱼       |
| 内存     | DDR4 2666MHz 16G + 32G          | 淘宝       |
| 电源     | 长城 200W                       | 淘宝       |
| 主板     | Nasse B365                      | 淘宝       |
| 机箱     | 迎广 MS04                       | 淘宝       |
| 网卡     | 发热王 Intel X540-T2            | 闲鱼       |
| M.2 硬盘 | Samsung PM9A1 1TB               | 闲鱼       |
| M.2 硬盘 | Samsung PM983 256GB             | 同学       |
| SSD 硬盘 | Kingston KC600 256GB            | 家里圣遗物 |
| HDD 硬盘 | Seagate IronWolf 4TB            | 淘宝       |
| HDD 硬盘 | WD Purple 4TB                   | 同学       |
| HDD 硬盘 | WD HC530 14TB                   | 淘宝       |

使用 PVE 作为底层系统安装在 PM983 上，黑群晖是虚拟机，由 RR 引导启动，直通了 PM9A1 和 SATA 控制器。

![](https://img.mk1.io/img/2025-11-10-3ff4c5ebf08c5fe6d28f9f6177018caa.png)

安装的套件不多，大部分服务都运行在 Docker 里：

- Tachidesk：看小说
- MCSManager：开创创 MC 服
- Alist：挂小网盘
- Reader：看小说
- Forgejo：存小代码
- VaultWarden：密码库
- Matrix：矩阵 HomeServer 与桥
- Lucky：反代 + STUN 穿透
- Mastodon：长毛象
- Authentik：SSO
- WatchTower：自动更新容器

除了以上服务还有一些影视相关服务比如 MoviePilot、qBittorrent，ChineseSubFinder 和 Emby，在外通过机器人选择需要的资源就能自动下载刮削入库，回家就能看啦（x

## 2024 总结

### 学习

高三了，压力很大 但奈何有的傻比还喜欢搞抽象

德育处头发是每周都要查的，班主任是自我意识过剩的，体育馆是关了半年但没见有人修过的

班主任 40 多岁还没结婚，疑似有情感障碍，给大家放一点经典语录

1. "来 **，过来一下，刚刚我走过去的时候为什么把门关上，是不是对我有什么意见" （** 是我的名字）

其实只是这位路过的时候正好有风吹过我就关了个门，没想到他的自我意识有点溢出

2. How↓e↑ver↓

其人在读英语文章的时候读到这个词总会抑扬顿挫发出奇怪的声音，导致已经无法直视这个词

3. 关你屁事！

此人某天来班上找一个同学，但他实在是太喜感导致有人爆笑如雷 于是上英语课时此人对着全班发出了战吼。全文为 "我见一次骂一次，关你屁事！"

在四个月的时间里此人金句频出，已经成为了一个行走的笑话🤣

说回正题，高三上学期除了英语别的科目已经全部开始一轮复习，进度最慢的英语也在一周前结束了课内的课程。不过本校一贯的作风是不参加市质检自主命题，导致整个学期除了还没到来的期末考没有一次是全省排名的大考😢T8 联考今年也没参加，估计是卷子太屑了罢（
