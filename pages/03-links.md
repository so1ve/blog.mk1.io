申请格式：

```ts
interface Link {
  name: "网站名称";
  description: "网站描述";
  url: "https://example.com";
  avatar?: "https://example.com/logo.png";
}
```

要求：

- 网站以个人为主体，内容健康，内容符合中国大陆的法律法规
- 拥有独立域名，全站 HTTPS
- 建站时间在半年以上，原创文章大于 5 篇，言之有物
- 需要有独立页面展示友情链接

请注意：

- 即使满足上述所有条件，本站仍保留对友链的审核权利。我会根据友链质量、内容相关性等进行主观判断。
- 本站会不定期对所有友链进行检查，若发现 3 个月以上不能正常访问或友链被取消，则会在无通知的情况下取消该友链，望周知。
